# parqueadero-uc

La universidad quiere digitalizar el control de un parqueadero pequeño; este debe atender 3 tipos de usuarios (Estudiantes, Docentes y Visitantes). Cada tipo de usuario paga tarifa distinta y tiene reglas distintas de acceso. Se usara todo lo visto en clase ( sin funciones definidas por el usuario, sin listas/diccionarios, sin POO). El programa debe simular el registro de entradas de vehiculos durante el dia, calcular cobros, aplicar descuentos y llevar estadisticas.
